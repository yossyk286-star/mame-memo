# まめメモ

カフェで飲んだコーヒーを記録して、記録するうちに詳しくなるアプリ（PWA）。

- **記録**: 店名・産地・焙煎度・精製方法・抽出方法・味の評価などを残す。入力中に「?」で用語の説明が見られる
- **辞典**: 精製方法・抽出方法・焙煎度・フレーバー表現の用語集と、選び方の目安
- **好み**: 記録が5件たまると傾向を表示（準備中）

- **メニュー撮影**: 記録画面でメニューを撮ると、豆の情報を読み取って解説とおすすめを出し、フォームに入れる（Claude API を使用）

データは端末内（IndexedDB）にだけ保存されます。設定画面からファイルに書き出し／読み込みができます。

## 開発

```bash
npm install
npm run dev   # http://localhost:3000
```

Next.js (App Router) / TypeScript。Vercel にそのままデプロイできます。

## 環境変数（メニュー撮影を使う場合）

| 名前 | 内容 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API のキー。Console で月の利用上限を設定しておく |
| `APP_PASSCODE` | 撮影機能の合言葉。他人に API を使われないためのもの |
| `MENU_MODEL` | 任意。使うモデル（既定は `claude-haiku-5-5`） |
